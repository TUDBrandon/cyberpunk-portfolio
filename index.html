TECHNICAL_LABS & PROJECTS

LAB-01 // DEFENSIVE MONITORING THREAT INTEL

T-POT_HONEYPOT // MULTI-HONEYPOT TELEMETRY

Set up a T-Pot honeypot lab and collected threat telemetry over a two-week period. Searched and analyzed the logs using the ELK stack and Splunk, finding log evidence of Mirai, Outlaw, and RedTail botnet traffic as well as WannaCry ransomware and ZombieBoy malware.

LAB-02 // OFFENSIVE TESTING WIRELESS RECON

AIR_CRACK // 802.11 RECON & CRACKING LAB

Set up a home router as a dedicated wireless testbed to practice password cracking over both legacy WEP and modern WPA networks. Captured wireless packets, broke WEP keys through IV recovery, and practiced WPA 4-way handshake capture and dictionary cracking in Kali Linux.

Kali Linux Aircrack-ng WEP & WPA 802.11 Protocols
LAB-03 // FORENSIC RESEARCH THESIS PROJECT

SOLID_STATE_FORENSICS // SSD SECURE DELETION

Collaborative thesis project (team of 3) investigating how secure file deletion works on SSDs across Linux, Windows, and macOS, comparing differences to evaluate OS-level security. Highlighted that this did not test firmware-level data because SSDs manage storage through a Flash Translation Layer (FTL) and wear leveling that the OS cannot directly bypass, demonstrating a practical understanding of how SSD storage differs fundamentally from traditional HDDs.

Digital Forensics SSD vs HDD Flash Translation Layer (FTL) Linux / Win / Mac File Carving

SEC_WEB_SYSTEMS // SECURE WEB PLATFORMS
