LAB-03 // FORENSIC RESEARCH THESIS PROJECT

SOLID_STATE_FORENSICS // SSD SECURE DELETION

Collaborative thesis research (team of 3) evaluating secure file deletion mechanisms across Linux, Windows, and macOS, benchmarking residual data recovery across native file systems (ext4, NTFS, APFS). Architectural insight: Addressed how SSDs fundamentally differ from HDDs—OS-level deletion commands cannot guarantee true physical block eradication due to the Flash Translation Layer (FTL), wear-leveling algorithms, and over-provisioning tables abstracting physical NAND flash from the OS.

Digital Forensics SSD vs HDD Flash Translation Layer (FTL) Linux / Win / Mac File Carving
